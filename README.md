# GatekeeperOS — Community and Organization Profile

Organization-profile content and shared community files for GatekeeperOS, an independent capability and approvals layer for OpenClaw.

[Organization profile](profile/README.md) · [Core project](https://github.com/gatekeeper-os/gatekeeper-os) · [Community gatekeepers](https://github.com/gatekeeper-os/gatekeepers)

## Where to start

- Read [the core project README](https://github.com/gatekeeper-os/gatekeeper-os#readme) for current releases, compatibility, setup, and limitations.
- Edit [profile/README.md](profile/README.md) to update the GitHub organization’s public introduction.
- Consult [the security policy](SECURITY.md) for vulnerability reporting.

## Maintaining public information

Check release and compatibility claims against the core repository before changing the profile. Distinguish controlled acceptance tests from real-provider deployment evidence. Preserve upstream attribution and avoid presenting prototypes as audited production security.

GatekeeperOS is independent and is not affiliated with or endorsed by the OpenClaw Foundation. OpenClaw is a trademark of its owner.
